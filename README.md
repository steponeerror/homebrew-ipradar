# homebrew-ipradar

Homebrew tap for [IP Radar Desktop](https://github.com/steponeerror/ip-radar-desktop).

```bash
brew install steponeerror/ipradar/ip-radar-desktop
```

- aarch64-only: Apple Silicon (arm64) builds only (`depends_on arch: :arm64`)
- 未签名 / not signed & notarized: 首次打开需右键 → 打开(或 `xattr -dr com.apple.quarantine "/Applications/IP Radar Desktop.app"`)
